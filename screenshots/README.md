## طريقة أخذ اللقطات

1. شغّل النظام (`dotnet run --project src/HR.Web`) وافتح `https://localhost:7188`
2. سجّل الدخول بحساب `admin@hr.sa / Admin@123`
3. خذ لقطة لكل صفحة بالدقة الموصى بها: **1920×1080** أو **1440×900**
4. احفظ كل لقطة داخل هذا المجلد بالاسم المذكور في الصف الرئيسي `README.md`

### نصائح لقطات احترافية
- استخدم معدّة Zoom أو أدوات مثل **ShareX** / **Snipaste** للتقاط كامل الصفحة
- املأ البيانات التجريبية أولاً (موظفون، إدارات، إجازات) حتى تظهر اللقطات واقعية
- وثّق لقطة رد المساعد الذكي وهو يرد بالعربية

> ملفات `.svg` الموجودة حالياً هي **Placeholders** تظهر في README حتى تُستبدل بلقطات حقيقية `.png` بنفس الاسم — بعدها حدّث مسارات الصور في `README.md`.

## How to capture (EN)

1. Run the app and log in with `admin@hr.sa / Admin@123`
2. Capture each page at **1920×1080** (or 1440×900) and save it here with the exact filename listed above
3. The current `.svg` files are placeholders — replace them with real `.png` screenshots and update the image paths in the root `README.md`
