## نصائح لقطات احترافية (Windows)

- `Win + Shift + S` لالتقاط منطقة محددة بشاشة
- `Alt + PrtScn` لالتقاط النافذة النشطة فقط، ثم احفظها من Paint
- الدقة الموصى بها: **1280×720** أو أعلى
- اجعل الخطوط واضحة والنافذة مفصّلة ودون مظاهر مكتب مساحات عشوائية

> ✅ بعد الاستبدال لا يلزم أي تعديل على README — فقط استخدم نفس الاسم والمجلد.
